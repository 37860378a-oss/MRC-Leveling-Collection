# Perfiles

Cada perfil se alojará en su carpeta de clase/árbol de talentos. La carpeta contendrá:

- Archivo(s) de rotación en el formato que se confirme para el ejecutor MRC.
- README.md con compatibilidad, nivel mínimo, talentos, habilidades y controles.
- Registro de pruebas y cambios relevantes.

No se agregan perfiles vacíos como si estuvieran terminados. Cada uno se incorpora cuando su formato y comportamiento hayan sido revisados.
