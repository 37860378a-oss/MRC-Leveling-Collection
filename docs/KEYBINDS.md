# Convención inicial de controles MRC

Este documento define una propuesta común. Las teclas se podrán ajustar durante las pruebas y no se consideran definitivas hasta acordarlas en juego.

## Modos

| Entrada | Comportamiento |
|---|---|
| Sin modificador | Unitarget: prioridades para un objetivo |
| SHIFT mantenido | AoE: prioridades para varios enemigos |
| ALT mantenido | Cooldowns ofensivos (si el perfil lo admite) |
| CTRL mantenido | Utilidad/defensivos (si el perfil lo admite) |

## Reglas

1. Un modificador solo cambia el modo mientras está mantenido.
2. Si el personaje no aprendió una habilidad, el perfil debe omitirla sin romper la rotación.
3. No activar AoE por accidente en el modo Unitarget.
4. Cada perfil debe indicar qué controles implementa realmente.
5. Evitar conflictos entre modificadores y acciones del cliente o del ejecutor.

## Por confirmar

- Tecla global definitiva para AoE.
- Si ALT y CTRL se reservarán globalmente o se definirán por perfil.
- Cómo se manejará la pausa/desactivación manual del perfil.

## Ejemplos de diseño

- Hunter: SHIFT para Salva u otras prioridades AoE disponibles al nivel.
- Mage: SHIFT para Ventisca u otras prioridades AoE disponibles al nivel.

Los ejemplos son objetivos de diseño, no confirmación de que esos hechizos estén implementados.
